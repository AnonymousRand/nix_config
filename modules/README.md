# `modules/`

everything except very fundamental flake-related stuff should be in here :3

### notes

- when naming aspects, you should generally follow the filepaths starting from here; e.g. `den.aspects.utils.<name>` for an aspect in `./utils/<name>.nix` or `den.aspects.features.desktop.<name>` for an aspect in `./features/desktop/<name>.nix`. the same goes with declared options.
